# 🏃 Espace de travail — STAPS L1

Tous mes cours (Word, diapos, PDF, fiches) rangés au même endroit.

## Organisation

```
00-Organisation/        → emploi du temps, calendrier des examens, notes
S1/  (Semestre 1)
S2/  (Semestre 2)
  └── 01-Anatomie/
        ├── CM/               → diapos (.pptx / .pdf) des cours magistraux
        ├── TD/               → sujets et corrigés de TD
        ├── Mes-notes/        → mes prises de notes (.docx)
        ├── Fiches-revision/  → fiches de synthèse
        ├── Annales/          → anciens partiels
        └── README.md         → infos du cours + suivi des chapitres
```

Matières : Anatomie · Physiologie · Biomécanique · Neurosciences / contrôle moteur ·
Psychologie · Sociologie · Histoire du sport · Sciences de l'éducation · APSA ·
Méthodologie · Statistiques · Anglais.
Si une matière ne correspond pas à ta maquette, renomme ou supprime simplement le dossier.

## Règle de nommage des fichiers

`AAAA-MM-JJ_Matiere_TypeNumero_Sujet.ext`

Exemples :
- `2026-09-15_Anatomie_CM01_Membre-inferieur.pptx`
- `2026-09-22_Physio_TD02_Filieres-energetiques.docx`
- `Anatomie_Fiche_Muscles-cuisse.docx`

→ Les fichiers se trient tout seuls par date, et on retrouve tout en un coup d'œil.

## Routine conseillée
1. **Après chaque cours** : déposer les diapos dans `CM/` et ses notes dans `Mes-notes/`.
2. **Chaque semaine** : cocher le tableau de suivi dans le `README.md` de la matière.
3. **Fin de chapitre** : faire une fiche dans `Fiches-revision/`.
4. **3 semaines avant les partiels** : réviser avec les fiches + `Annales/`.

## Ajouter des fichiers
- **Depuis GitHub (navigateur)** : ouvrir le dossier voulu → *Add file* → *Upload files* → glisser-déposer → *Commit changes*.
- **Depuis Claude** : envoie-moi tes fichiers et je les range au bon endroit (et je peux en faire des fiches de révision !).

⚠️ Limite GitHub : 100 Mo par fichier (25 Mo via le navigateur). Pour les grosses vidéos, utiliser plutôt un Drive.
